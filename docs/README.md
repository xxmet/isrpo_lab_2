# Общее описание

Это учебный проект для ***лабораторной работы по ИСРПО №2***.  
В проекте два файла с кодом на Python: ***square.py*** и ***circle.py***.  
Они нужны для вычисления площади и периметра геометрических фигур (квадрата и круга).  


# Описание функций

### Файл square.py
##### Функция area(a)
Принимает сторону квадрата a.  
Возвращает площадь квадрата (a * a).  
***Пример вызова:*** area(5) вернёт 25.  
##### Функция perimeter(a)
Принимает сторону квадрата a.  
Возвращает периметр квадрата (4 * a).  
***Пример вызова:*** perimeter(5) вернёт 20.  

### Файл circle.py
##### Функция area(r)
Принимает радиус круга r.  
Возвращает площадь круга (пи * r * r).  
***Пример вызова:*** area(5) вернёт примерно 78.54.  
##### Функция perimeter(r)
Принимает радиус круга r.  
Возвращает длину окружности (2 * пи * r).  
***Пример вызова:*** perimeter(5) вернёт примерно 31.42.
